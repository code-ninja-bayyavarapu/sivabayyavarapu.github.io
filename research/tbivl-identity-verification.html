TBIVL: A Unified Identity Verification Layer for Secure Agent-to-Service Context Exchange

Siva Rama Krishna Varma Bayyavarapu · Srinivasateja Songa · Siva Prasad Nandi

View official record Download BibTeX

Abstract

Secure agent-to-service context exchange requires strong guarantees that both the calling agent and the target service are authentic. TBIVL introduces a unified application-layer decision point that combines agent attestation, service authenticity validation, and request-scoped authorization before context is exchanged. Controlled experiments and large-scale simulations evaluated the framework across legitimate and spoofed entities, showing consistent rejection of malicious requests with minimal latency overhead. The work provides a practical security boundary for enterprise agents that invoke sensitive services and tools.
