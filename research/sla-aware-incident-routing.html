SLA-Aware Incident Detection and Alert Routing via MCP in Distributed Systems

Siva Rama Krishna Varma Bayyavarapu · Vijayakumar Venganti · Vishwanath Hiremath

Conference website Download BibTeX

Abstract

Modern distributed systems generate fragmented telemetry across interconnected services, making high-impact incidents difficult to distinguish from background noise. This paper presents an SLA-aware MCP pipeline that combines incremental incident grouping, adaptive anomaly detection, service-impact scoring, and capacity-aware routing. The evaluation uses OpenTelemetry-style microservice telemetry across repeated runs and reports higher precision and F1 performance than static thresholding and simple tag-and-time grouping, while keeping false positives within a defined alert budget. Scalability experiments show sub-millisecond median latency and throughput above 1,800 events per second.
